# Health Journal

این پروژه بخشی از دوره آموزشی React است. در هر درس، دانشجو با یک مسئله روبه‌رو می‌شود و مسیر حل مسئله را مرحله‌به‌مرحله طی می‌کند:

1. شناسایی و تحلیل مسئله
2. پیدا کردن راه‌حل‌های ممکن
3. بررسی راه‌حل‌ها و انتخاب گزینه مناسب
4. پیاده‌سازی و آزمایش راه‌حل
5. انجام یک تسک مشابه به‌صورت مستقل توسط دانشجو

## ساختار برنچ‌ها

- `main`: نقطه شروع پروژه و کدی که درس از آن آغاز می‌شود.
- `lesson02`، `lesson03` و ...: برنچ شروع هر درس. نام برنچ هر درس ممکن است متناسب با شماره درس تغییر کند.
- `final`: نسخه نهایی پیاده‌سازی‌شده پروژه برای مقایسه و بررسی نتیجه کار.

در هر درس، ابتدا روی برنچ همان درس کار کنید. پس از تلاش برای حل مسئله و انجام تسک، می‌توانید نتیجه خود را با برنچ درس بعد که شامل تمام تسک های درس قبل است، مقایسه کنید.

## پیش‌نیازها

- Node.js و npm
- دسترسی به اینترنت برای نصب وابستگی‌ها و ارتباط با API
- یک توکن معتبر از پنل کاربری در [api.imtaha.ir](https://api.imtaha.ir)

## دریافت و اجرای پروژه

### ۱. کلون کردن مخزن

```bash
git clone https://github.com/imtaha-ir/health-journal.git
cd health-journal
```

برای شروع یک درس مشخص، برنچ آن درس را دریافت و فعال کنید، مثلا برای شروع درس ۲:

```bash
git fetch --all
git switch lesson02
```

در صورت نیاز، `lesson02` را با نام برنچ درس موردنظر جایگزین کنید.

### ۲. نصب وابستگی‌ها

```bash
npm install
```

### ۳. ساخت فایل محیطی

فایل .env.sample را به `.env` تغییر نام دهید یا از روی آن یک کپی بسازید.

در PowerShell ویندوز:

```powershell
Copy-Item .env.sample .env
```

در macOS و Linux:

```bash
cp .env.sample .env
```

سپس فایل `.env` را باز کنید و توکن دریافتی از پنل [api.imtaha.ir](https://api.imtaha.ir) را در مقدار `VITE_API_TOKEN` قرار دهید. آدرس API در فایل نمونه تنظیم شده است:

```env
VITE_API_VITE_API_BASE_URL=https://api.imtaha.ir/api/react-health-journal
VITE_API_TOKEN=PASTE-YOUR-TOKEN-HERE
```

فایل `.env` را در اختیار دیگران قرار ندهید و توکن خود را در مخزن commit نکنید.

### ۴. اجرای برنامه در حالت توسعه

```bash
npm run dev
```

پس از اجرا، آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید؛ معمولاً آدرس برنامه `http://localhost:5173` است.

## دستورات کاربردی

```bash
npm run dev      # اجرای سرور توسعه
npm run build    # بررسی TypeScript و ساخت نسخه production
npm run lint     # بررسی خطاهای lint
npm run preview  # نمایش نسخه build شده
```
